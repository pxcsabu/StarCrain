# StarCrane — Modern Rust Planetarium & Astronomical Suite

**StarCrane** は、日本の名作フリー天文ソフト「つるちゃんのプラネタリウム（つるぷらフリー版）」の思想と全機能を完全再現し、さらに現代的なUI/UX・高精度計算・天体観測支援機能を追加した、クロスプラットフォーム対応の総合天文シミュレーションソフトウェアです。

---

## 0. 【最優先・絶対厳守】セキュリティ＆ウイルス感染防止ポリシー

**本プロジェクトを開発するすべてのAIエージェントおよび開発者は、以下のルールを最優先で厳守すること。違反する操作・提案は一切禁止する。**

1. **不審なコマンド・外部スクリプトの実行禁止**
   - `curl ... | sh`、`wget ... | bash`、`irm ... | iex` などのワンライナー実行を全面禁止する。
   - 出所不明のバイナリ・実行ファイル（`.exe`, `.msi`, `.dll`, `.bat`, `.ps1`, `.sh`, `.dmg`, `.pkg` 等）のダウンロードおよび実行を全面禁止する。
   - システム設定の変更、管理者権限（`sudo` / UAC昇格）の要求、Windows Defender 等のセキュリティソフトの無効化・除外設定の提案を全面禁止する。
2. **パッケージ導入の厳格管理（タイポスクワッティング／悪意ある依存対策）**
   - AIの推測・記憶任せでマイナーな Rust クレートや npm パッケージを勝手に追加しないこと。
   - 本 `README.md` に記載された実績のある主要クレート／パッケージ以外を追加する場合は、**必ず事前にユーザーへパッケージ名・公式URL・導入理由を提示して承認を得る**こと。
   - `pnpm` ではライフサイクルスクリプトの自動実行を制限し（`ignore-scripts` 確認）、依存追加後は必ずロックファイル（`Cargo.lock` / `pnpm-lock.yaml`）の差分と `cargo audit` / `pnpm audit` で脆弱性・不審な挙動を確認すること。
   - `build.rs` やビルドスクリプト内で外部ネットワーク通信やバイナリダウンロードを行う処理を書いてはならない。
3. **外部天文データの取得元ホワイトリスト（テキストデータ限定）**
   - 外部データの取得は、**HTTPS かつ以下の信頼できる公式一次配布元のみ**に限定し、純粋なテキストデータ（CSV / JSON / TXT）としてパースすること（実行可能形式や不明なアーカイブは禁止）。
     - 恒星カタログ（HYG）: `https://github.com/astronexus/HYG-Database`（または Codeberg 公式リポジトリ）
     - 星雲・星団（OpenNGC）: `https://github.com/mattiaverga/OpenNGC`
     - 星座線・境界線・天の川（d3-celestial）: `https://github.com/ofrohn/d3-celestial`
     - 彗星軌道要素（MPC公式）: `https://minorplanetcenter.net/`
     - 人工衛星TLE（CelesTrak公式）: `https://celestrak.org/`
     - 天気・雲量予報（Open-Meteo公式）: `https://api.open-meteo.com/`
   - 取得したデータファイルには絶対に実行権限を付与しないこと。
4. **アプリ自体の最小権限設計（Tauri v2 Capabilities）**
   - Tauri v2 の権限設定（`src-tauri/capabilities/`）は最小権限の原則に従い、ファイル読み書きはアプリ専用データディレクトリおよびユーザーが明示的にダイアログ選択したファイルのみに限定する。
   - ネットワークアクセスは上記ホワイトリストドメインのみ許可し、オフライン動作モードをデフォルトで選択可能にする。

## 1. コンセプトと設計原則

1. **つるぷらフリー版の機能 100% 完全互換**
   - 9つの図法、過去・未来モード（歳差・固有運動）、別の惑星モード、月齢カレンダー、流星群、3D太陽系、惑星解析ツール群、天文計算機、時計・タイマー、星図印刷まで余さず実装する。
   - つるぷらの良さである「ワンクリックで直感的に操作できる手軽さ」「日本の観測者に寄り添った情報（旧暦・六曜・日本各地プリセット・分かりやすい解説）」を大切にする。
2. **フリー版制限の撤廃とさらなる機能拡張**
   - 恒星数・星雲星団数・倍率制限・食現象（日食・月食・日面通過）・惑星現象検索などの制限を撤廃し、さらに現代的な観測機能（カメラFOV枠、ISS/人工衛星追跡、MPC彗星オンライン同期、赤色ナイトビジョン等）を統合する。
3. **脱・古いMDIウィンドウ → モダンで没入感のあるUI**
   - 古いマルチウィンドウ（MDI）を廃止し、**全画面の星空キャンバスを主役**としたモダンなフローティング／ドッキングUIを採用する。
   - ボタン操作のわかりやすさを維持しつつ、マウスドラッグ回転・ホイールズーム・コマンドパレット（`Ctrl+K` / `Cmd+K`）による高速操作を両立する。
4. **Rust による圧倒的な計算速度と精度**
   - 全ての天体暦・座標変換・現象探索を Rust で実装し、マルチスレッド並列化により数百年分の惑星接近検索や食現象検索を瞬時に完了させる。

## 4. 機能仕様一覧

### A. つるぷらフリー版 完全互換機能（必須コア）

#### 1. 9つの図法（投影法）
1. **好きな方向**: 任意の方位・高度を中心とする透視／ステレオ投影。マウスドラッグでの自由回転・つるぷら式の方角ボタン（北・東・南・西・天頂等）の両対応。
2. **全球プラネタリウム**: 星座早見盤形式の全天円形図（正距方位図法）。
3. **半球プラネタリウム（大1個）**: 見た目の形に近い半球1面表示。
4. **半球プラネタリウム（小2個）**: 2つの方向（例：南の空と北の空）を左右に同時表示。
5. **全体表示**: 全天360°パノラマ展開図（円筒／モルワイデ／正距円筒切替可）。
6. **星図形式**: 赤経・赤緯を基準とした高精度星図（星座・惑星・任意座標を中心に高倍率表示）。
7. **地平線方向拡大**: 地平線付近の低空現象（日の出・夕焼け・水星・彗星等）に最適化した拡大図。
8. **空の中ほど**: 高度30°〜60°付近の中空を見やすく投影。
9. **天頂方向**: 真上を見上げた天頂中心図。

#### 2. 表示モード
* **プラネタリウムモード（通常）**: 1900年〜2200年（拡張：紀元前3000年〜西暦5000年）の精密星空。
* **過去・未来モード**:
  * **歳差運動＋固有運動**: 前後1万5千年の地球自転軸の傾き変化（北極星の移り変わり）と「極軸の動き」の図示。
  * **固有運動のみ**: 前後10万年の恒星移動による星座の形の変化をシミュレーション。
* **別の惑星モード**: 水星・金星・火星・木星・土星・天王星・海王星・月から見た星空、太陽、地球の形と動きを再現。

#### 3. 表示対象レイヤーとリアル表現
* **天体**: 恒星（等級スライダーで2等〜10等超まで調整可）、恒星の色（スペクトル/B-V対応）、太陽、月（満ち欠け描画）、惑星・準惑星（冥王星・エリス含む）、星雲・星団（メシエ全110天体＋NGC/IC）、彗星、変光星。
* **ガイドライン・ラベル**: 星座線（簡易・標準・詳細）、星座名、星座境界線、星座絵、恒星固有名、星名（αβγ・フラムスティード）、惑星名称、星雲星団名称、天の川、天頂マーク、星空の目印（春・夏・冬の大三角、秋の四辺形等）、天の赤道・黄道、赤経・赤緯線、方位・高度線、数値目盛。
* **リアル空背景**:
  * 日中の青空
  * 朝焼け・夕焼け（太陽方位に応じたリアルな色グラデーション）
  * 地平線付近の色合い変化・大気減光
  * 月明かりの擬似表現（月齢・月高度連動）
  * 都会の夜空（最微光星等級／ボートルスケール連動の光害表現）

#### 4. 日時・観測地・シミュレーション・自動運転
* **日時操作**: 直接入力、カレンダー、スライダー、特定時刻ワンクリック設定（日の出・日の入り・月の出・月の入り・天文薄明開始/終了・南中）、星図上からの簡易日時変更ボタン。
* **観測地管理**: 日本各地・海外主要都市プリセット、緯度・経度・標高・タイムゾーンの自由追加・編集・削除・順序変更。
* **シミュレーション**:
  * 変動パラメータ: 時間/日付、緯度、視点
  * 固定オプション: 固定なし、星座固定、惑星固定、日の出/日の入り固定
  * **重ねて表示（トレイル描画）**: 画面をクリアせず上書き描画し、惑星逆行・アナレンマ・日周軌跡・固有運動軌跡を可視化。
* **自動運転**: 現在時刻の星空をリアルタイムで自動更新。

#### 5. 検索・インスペクタ・観測データ
* **クリック検索**: 星図上のあらゆる天体をクリックして詳細データ（座標・方位高度・等級・距離・出没時刻・南中時刻・写真・解説）を表示。
* **名前で検索**: 星座、恒星（固有名・αβγ・番星・星座・赤経・変光星・明るさ絞込）、惑星、星雲・星団（番号・愛称・写真ギャラリー）、星空の目印。
* **近くに見える天体**: 太陽・月・惑星・任意座標の付近にある天体を角距離順に一覧表示し、選択でセンタリング。
* **当日の観測データ画面**: 日の出/入・月の出/入・薄明・月齢・旧暦・六曜・二十四節気・当日の天文現象一覧・プラネタリウム日時同期。

#### 6. 惑星・月・流星群・食・太陽系・その他サブツール
* **惑星ツール群**:
  * 惑星情報（基本データ＋日時ステップ変更）
  * 惑星の形（水星・金星・火星・月・土星の環・木星、赤経赤緯基準／地平基準）
  * 惑星の経路（順行・逆行の星図上トレース、上書き描画対応）
  * 内惑星と太陽の赤経・赤緯差グラフ（水星・金星両対応、形の同時表示）
  * 惑星の光度曲線グラフ（水星〜土星・彗星、期間1ヶ月/3ヶ月/6ヶ月/1年切替＆スクロール）
  * 惑星現象検索（全惑星対象の衝・合/外合/内合・留・東矩/西矩・最大離角＋プラネタリウム連動）
  * 惑星同士・惑星と恒星の接近検索（複数惑星の集合検索含む＋ダブルクリックでプラネタリウム連動）
* **3D太陽系シミュレーター**: 太陽系惑星の3D軌道・位置表示、自由なカメラ回転・ズーム、時間アニメーション、軌道色分け、背景星空表示。
* **月齢カレンダー**: 1ヶ月単位の月相イラスト表示、日本の祝日赤字表示、旧暦・六曜併記、日付クリックでプラネタリウム連携。
* **流星群**: 年間主要21個＋αの情報・極大日と月齢一覧表・極大日ジャンプ・プラネタリウム上の流星出現イメージアニメーション（放射点からの飛び出し演出）。
* **食現象**: 恒星食（星食）、日食（皆既/金環/部分）、月食（皆既/部分/半影）、水星・金星の日面通過の検索、欠け方向・食分・開始/最大/終了時刻表示、連続経路表示。
* **彗星データ設定**: 軌道要素（近日点通過時刻・近日点距離・離心率・軌道傾斜角・昇交点黄経・近日点引数・光度パラメータ）の登録・編集・削除（件数無制限）。
* **変光星**: 星座・星名・極大光度での絞り込み、情報表示、プラネタリウム位置表示。
* **星座の解説と神話・恒星の解説**: 全88星座の解説・見つけ方・神話および主要恒星解説。解説画面からボタン1つでプラネタリウムへジャンプ。
* **天文計算機**: ユリウス日（JD）、修正ユリウス日（MJD）、地方恒星時（LST）、時角、経過日数、経過時間、赤経赤緯→角距離、高度→時刻、B1950↔J2000座標変換。
* **時計＆タイマー**: 秒針付きアナログ/デジタル時計、時報、残り時間タイマー、指定時刻アラーム、音ON/OFF。
* **印刷・エクスポート**: A4/B5用紙対応、印刷オプション（黒地白星／白地黒星の色反転、モノクロ星図など）、高解像度PNG/SVG/PDF保存。

### B. モダン拡張・新規追加機能（＋αの便利機能）

1. **天体観測用「ナイトビジョン（赤色暗順応）モード」**: 画面全体を暗順応を妨げない深紅パレットへ1クリック切替（星図・UIパネル・文字すべて対応）。
2. **コマンドパレット (`Ctrl+K` / `Cmd+K`)**: キーボードだけで「オリオン座」「M31」「次の皆既月食」「2026-12-15 02:00」「ナイトビジョン」などを瞬時に検索・実行。
3. **別の恒星モード（3D星間飛行）**: HYGカタログの距離（視差）を使い、シリウスやケンタウルス座α星など別の恒星系から見た歪んだ星座を再現。
4. **木星ガリレオ衛星＆大赤斑ツール**: イオ・エウロパ・ガニメデ・カリストのリアルタイム位置図・波動曲線（日付推移グラフ）・大赤斑（GRS）の正中時刻予報。
5. **天体撮影・観望支援（FOV & 高度推移）**:
   - カメラセンサーサイズ＋焦点距離、または望遠鏡＋アイピースの視野枠（FOVフレーム・テルラドサークル）を星図に重ね描き。
   - 選択天体の「今夜（24時間）の高度変化グラフ」をインスペクタ内に表示（天文薄明帯・南中時刻・月との離角も同時表示）。
6. **オンライン最新データ同期（完全オプトイン・公式API限定）**:
   - MPC（小惑星センター）から最新彗星の軌道要素を自動取得・インポート。
   - CelesTrakから最新のTLEを取得し、**ISS（国際宇宙ステーション）や主要人工衛星**の通過予報とリアルタイム星図追跡。
   - Open-Meteo による観測地の今夜の雲量・透明度予報ウィジェット（オフライン時は自動非表示）。
7. **インタラクティブ地図ピッカー＆表示色テーマ**: 観測地登録時の地図クリック入力、設定のJSONインポート／エクスポート。

## 5. モダンUI/UXデザインガイドライン

* **レイアウト**:
  * **中央（100%ビューポート）**: 星図キャンバス。余計な枠を排し没入感を最大化。
  * **上部フローティングバー（半透明ガラス調）**: 観測日時・観測地・図法切替・検索トリガー（`Ctrl+K`）・テーマ切替（ダーク／ナイトビジョン）をコンパクトに集約。
  * **左ドック（折りたたみ可）**: つるぷら伝統のワンクリック操作を現代アイコン化したクイックツールバー（レイヤーON/OFF、方角ボタン、倍率、モード切替）。
  * **右インスペクタ／ドロワー（必要時展開）**: クリックした天体の詳細、観測データ、各種解析ツールをタブ／モーダル／スライドパネルで整理。
  * **下部タイムラインバー（折りたたみ可）**: 時間再生・速度調整・ステップ送り・重ね描きトグルを動画プレイヤーのように直感操作。
* **タイポグラフィ**: 日本語は `Noto Sans JP` / システムUIフォント、数値・座標（赤経・赤緯・時刻）は桁ズレ防止のため等幅フォント（`tabular-nums` / `JetBrains Mono`）を使用。
* **ショートカットキー**: スペース（再生/停止）、`[` `]`（時間ステップ）、`+` `-`（ズーム）、`C`（星座線）、`L`（ラベル）、`G`（グリッド）、`R`（ナイトビジョン）、`Ctrl+K`（検索）。

## 6. 開発・ビルド・セキュリティ監査手順

### 前提環境
* Rust (stable 1.85+) & Cargo（必ず公式 `https://rustup.rs/` から導入）
* Node.js (LTS v20+) & pnpm（必ず公式サイトから導入）
* Tauri v2 システム依存関係（公式ガイド `https://v2.tauri.app/` 準拠）

### セットアップと起動

```bash
# 依存パッケージのインストール（スクリプト実行を監視しつつ導入）
pnpm install

# セキュリティ監査（脆弱性・不審な依存チェック）
pnpm audit
cargo audit --file src-tauri/Cargo.lock

# カタログデータの初期変換（ローカルに配置した公式CSV/JSONから生成）
cargo run --manifest-path data-pipeline/Cargo.toml

# 開発サーバー起動（Rust + Vite ホットリロード）
pnpm tauri dev

# Rust 天文計算エンジンの単体テスト実行
cargo test --manifest-path src-tauri/Cargo.toml

# プロダクションビルド
pnpm tauri build
```
